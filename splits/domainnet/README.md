# DomainNet split files

Generated by `tools/data/prepare_domainnet_splits.py`. Do not edit by hand.

All styles share one class split: labels 0-172 are base and 173-344 are
new, in the label order of the official cleaned lists. `classnames.json` holds the 345
names in that order. Few-shot files hold base classes only. Train and val sizes are the same for
seeds 1, 2, 3. Val comes from train, outside the 16-shot draw, and never from test.

`test_subset.json` holds up to 50 images per class, drawn once, and is the same for every
method and seed. Per-class counts are in `audit.csv`.
